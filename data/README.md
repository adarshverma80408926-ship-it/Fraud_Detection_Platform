# Dataset

This project uses the Credit Card Fraud Detection dataset from the
Machine Learning Group at Universite Libre de Bruxelles (ULB).

Dataset characteristics:
- 284,807 transactions
- 492 fraudulent transactions
- Fraud rate: approximately 0.172%
- Features: Time, V1-V28, Amount
- Target: Class

The raw creditcard.csv file is intentionally not committed to GitHub
because of its large file size.

Place the downloaded dataset here:

data/raw/creditcard.csv
